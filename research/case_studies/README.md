# Case studies

The 15 case studies the praxis research used to evaluate AegisShield, each a system whose threat model was published in a paper. Each file opens with a reference to that paper and its DOI, then gives the system's key attributes, a description of the system, and its scores on the rubric below. The expert-developed threat models themselves are in the cited papers, not in this folder. [`../batch/inputs/`](../batch/inputs/) holds one batch input per case study.

## Rubric

[`rubric_criteria.md`](rubric_criteria.md) scores each case study's input from 1 to 5 on nine criteria: application description, application type, industry sector, data sensitivity, internet exposure, compliance requirements, authentication methods, technical details, and threat details.

See [`../README.md`](../README.md) for how the case studies fit with the batch runs and the notebook.
